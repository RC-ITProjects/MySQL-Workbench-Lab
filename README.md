# MySQL Workbench

DBMS practice for Database Principles (Fall 2026), written and run in MySQL Workbench.

## Folder layout

| Folder | What goes in it |
| --- | --- |
| `scripts/` | Scripts I was given (class files, sample databases), kept unchanged |
| `practice/` | SQL I write myself, one file per topic or session |
| `models/` | MySQL Workbench EER diagrams (`.mwb`) and exported images |
| `LOG.md` | Short dated notes on what I practiced and learned |

## Skills practiced

- [ ] Creating databases and tables (`CREATE`, data types, keys)
- [ ] Inserting, updating, deleting rows
- [ ] `SELECT` with `WHERE`, `ORDER BY`, `LIMIT`
- [ ] Joins (`INNER`, `LEFT`, `RIGHT`)
- [ ] Aggregates and `GROUP BY` / `HAVING`
- [ ] Subqueries
- [ ] Views, indexes, stored procedures
- [ ] ER modeling in Workbench

## Running a script

1. Open MySQL Workbench and connect to your local server.
2. **File > Open SQL Script** and choose a `.sql` file from this repo.
3. Run everything with the lightning bolt, or the current statement with **Ctrl+Enter**.
